# 数据说明

## 1. 文档目的

整理当前赛题涉及的数据文件、模板结构及可确认的数据特征，为后续建模和程序开发提供统一的数据说明。

## 2. 输入信息来源

- 赛题原文（赛题原文.md）
- result1.xlsx
- result2.xlsx
- result3.xlsx

未提供数据字典或附件说明文件。

## 3. 核心内容

### 3.1 数据文件概况

| 文件 | 格式 | 用途 |
|---|---|---|
| 赛题原文.md | Markdown | 保存赛题说明、条件及问题要求 |
| result1.xlsx | Excel | 问题3结果填写模板 |
| result2.xlsx | Excel | 问题4结果填写模板 |
| result3.xlsx | Excel | 问题5结果填写模板 |

### 3.2 各Excel模板字段

#### result1.xlsx

共10个字段：

1. 无人机运动方向（项目输出约定：航向角）
2. 无人机运动速度（m/s，数值型）
3. 烟幕干扰弹编号（整数）
4. 投放点x坐标（m）
5. 投放点y坐标（m）
6. 投放点z坐标（m）
7. 起爆点x坐标（m）
8. 起爆点y坐标（m）
9. 起爆点z坐标（m）
10. 有效干扰时长（s）

模板预留3枚烟幕干扰弹记录。

#### result2.xlsx

共10个字段：

1. 无人机编号（文本）
2. 无人机运动方向（项目输出约定：航向角）
3. 无人机运动速度（m/s）
4. 投放点x坐标（m）
5. 投放点y坐标（m）
6. 投放点z坐标（m）
7. 起爆点x坐标（m）
8. 起爆点y坐标（m）
9. 起爆点z坐标（m）
10. 有效干扰时长（s）

模板预置FY1、FY2、FY3三架无人机。

#### result3.xlsx

共12个字段：

1. 无人机编号
2. 无人机运动方向（项目输出约定：航向角）
3. 无人机运动速度（m/s）
4. 烟幕干扰弹编号
5. 投放点x坐标（m）
6. 投放点y坐标（m）
7. 投放点z坐标（m）
8. 起爆点x坐标（m）
9. 起爆点y坐标（m）
10. 起爆点z坐标（m）
11. 有效干扰时长（s）
12. 干扰的导弹编号

模板共预留15条记录（5架无人机×3枚烟幕弹）。

### 3.3 数据规模、时间范围与空间范围

- 原始数据均为模板文件，不包含计算结果。
- 时间范围：无时间序列数据。
- 空间范围：采用赛题三维坐标系，单位为米。

### 3.4 数据关联关系

| 数据表 | 关联字段 |
|---|---|
| result1 | 烟幕干扰弹编号 |
| result2 | 无人机编号 |
| result3 | 无人机编号、烟幕干扰弹编号、干扰的导弹编号 |

其中无人机编号与赛题中的FY1~FY5一致；导弹编号与M1~M3一致。

### 3.5 数据质量检查

- 缺失值：除编号列外，其余均为空白模板。
- 异常值：未发现。
- 重复值：无。
- 单位问题：模板未注明运动方向表达方式；项目统一填写从 $+x$ 轴逆时针计量的 $[0,360^\circ)$ 航向角。内部计算仍使用弧度。

### 3.6 暂时无法理解的字段

- 无人机运动方向：官方模板未说明编码；项目已确定使用航向角。

### 3.6.1 项目输出约定

1. 航向角从 $+x$ 轴起逆时针计量，Excel填写 $[0,360^\circ)$ 的角度值。
2. “有效干扰时长”填写按全部实际投放弹的全局投放顺序计算的、对该行标记导弹的新增遮蔽时长；同刻按无人机编号、烟幕弹编号排序。
3. 所有数值字段保留3位小数；完整精度结果另存，用于模型回代。
4. 问题5中“干扰的导弹编号”表示主要任务目标；同一烟幕对其他导弹形成的实际遮蔽仍计入相应导弹总时长。

### 3.7 可能需要补充的外部数据

当前赛题求解无需额外数据即可建立模型。

若需要提高模型真实性，可补充：
- 空气阻力参数；
- 风场数据；
- 烟幕扩散参数；
- 无人机动力学参数。

上述均属于扩展研究，不属于赛题提供数据。

## 4. 关键结论

1. 当前数据均为结果填写模板，不含实验数据。
2. 三个Excel模板分别对应问题3、4、5。
3. 字段设计能够覆盖无人机、烟幕弹、导弹三类对象。
4. 项目已统一方向、单弹时长和小数位数的输出约定；这些属于项目实施规范，不是官方模板新增说明。
