## 3. 核心内容

### 3.1 赛题背景

烟幕干扰弹主要通过化学燃烧或爆炸分散形成烟幕或气溶胶云团，在目标前方特定空域形成遮蔽，干扰敌方导弹，具有成本低、效费比高等优点。随着烟幕干扰技术的不断发展，现已有多种投放方式完成烟幕干扰弹的定点精确抛撒，即在抛撒前能精确控制烟幕干扰弹到达预定位置，通过时间引信时序控制起爆时间。

现考虑运用无人机完成烟幕干扰弹的投放策略问题。具有长续航能力的无人机挂载某型烟幕干扰弹在特定空域巡飞，受领任务后，无人机投放烟幕干扰弹，在来袭武器和保护目标之间形成烟幕遮蔽。

在导弹来袭过程中，通过投放烟幕干扰弹尽量避免来袭导弹发现真目标。控制中心在警戒雷达发现目标时，立即向无人机指派任务。

为实现更为有效的烟幕干扰效果，需设计烟幕干扰弹的投放策略，主要包括无人机飞行方向、飞行速度、烟幕干扰弹投放点、烟幕干扰弹起爆点等。请建立数学模型，针对不同情形，分别设计烟幕干扰弹的投放策略，使得多枚烟幕干扰弹对真目标的有效遮蔽时间尽可能长。不同烟幕干扰弹的遮蔽可不连续。

### 3.2 赛题明确给出的条件

#### 3.2.1 烟幕干扰弹及烟幕云团

1. 每架无人机投放两枚烟幕干扰弹至少间隔 `1 s`。
2. 烟幕干扰弹脱离无人机后，在重力作用下运动。
3. 烟幕干扰弹起爆后瞬时形成球状烟幕云团。
4. 烟幕云团以 `3 m/s` 的速度匀速下沉。
5. 据试验数据，云团中心 `10 m` 范围内的烟幕浓度在起爆 `20 s` 内可为目标提供有效遮蔽。

#### 3.2.2 来袭导弹

1. 来袭武器为空地导弹。
2. 导弹飞行速度为 `300 m/s`。
3. 导弹的飞行方向直指为掩护真目标而专门设置的假目标。
4. 警戒雷达发现来袭导弹时，3 枚导弹的位置分别为：

| 导弹 | 初始位置 |
|---|---|
| M1 | `(20000, 0, 2000)` |
| M2 | `(19000, 600, 2100)` |
| M3 | `(18000, -600, 1900)` |

#### 3.2.3 坐标系与目标

1. 以假目标为原点。
2. 水平面为 $xy$ 平面。
3. 真目标为半径 `7 m`、高 `10 m` 的圆柱形固定目标。
4. 真目标下底面的圆心为：

$$
(0, 200, 0)
$$

#### 3.2.4 无人机

警戒雷达发现来袭导弹时，5 架无人机的位置分别为：

| 无人机 | 初始位置 |
|---|---|
| FY1 | `(17800, 0, 1800)` |
| FY2 | `(12000, 1400, 1400)` |
| FY3 | `(6000, -3000, 700)` |
| FY4 | `(11000, 2000, 1800)` |
| FY5 | `(13000, -2000, 1300)` |

无人机受领任务后的运动条件如下：

1. 可根据需要瞬时调整飞行方向。
2. 以 `70~140 m/s` 的速度等高度匀速直线飞行。
3. 每架无人机的航向、速度可不相同。
4. 每架无人机的航向、速度一旦确定就不再调整。

### 3.3 各小问完整要求

#### 问题1

请给出烟幕干扰弹对 M1 的有效遮蔽时长。

### 3.6 特别限制或注意事项

1. 无人机受领任务后可以瞬时调整飞行方向，但航向和速度一旦确定，不再调整。
2. 无人机只能等高度、匀速、直线飞行，速度范围为 `70~140 m/s`。
3. 每架无人机连续投放两枚烟幕干扰弹的时间间隔不得小于 `1 s`。
4. 烟幕干扰弹脱离无人机后受重力作用运动。
5. 烟幕云团起爆后瞬时形成，并以 `3 m/s` 匀速下沉。
6. 有效烟幕范围为云团中心 `10 m` 范围内。
7. 单个烟幕云团的有效时间限于起爆后 `20 s` 内。
8. 多枚烟幕干扰弹产生的有效遮蔽可以不连续。
9. 总体目标是使多枚烟幕干扰弹对真目标的有效遮蔽时间尽可能长。
10. 问题5中每架无人机至多投放 3 枚烟幕干扰弹。

## 4. 关键结论

1. 赛题要求围绕无人机航向、速度、投放时刻与位置、起爆时刻与位置设计烟幕干扰弹投放策略。
2. 优化目标为延长对真目标的有效遮蔽时间，且允许不同烟幕弹的遮蔽时段不连续。
3. 问题由单机单弹的确定性计算逐步扩展到单机多弹、多机单弹和多机多弹、多导弹协同干扰。
4. 问题3至问题5需按照附件模板提交 Excel 结果文件。
