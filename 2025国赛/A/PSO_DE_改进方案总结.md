# PSO 与 DE 加速收敛且保证精度的改进方案

## 核心目标

在**不降低最终优化精度**的前提下，提高收敛速度、减少函数评估次数（FEs）和实际运行时间。

------------------------------------------------------------------------

# 一、总体优化思路

总时间近似为：

> 总时间 = 函数评估时间 + 算法计算时间 + 并行同步开销

因此应优先：

1.  并行计算适应度
2.  自适应参数控制
3.  动态缩减种群
4.  停滞检测与恢复
5.  后期局部搜索
6.  代理模型预筛选（昂贵目标函数）
7.  代码向量化、缓存

------------------------------------------------------------------------

# 二、PSO 改进方案

## 1. 自适应参数

根据种群多样性和收敛状态动态调整：

-   惯性权重 w
-   学习因子 c1
-   学习因子 c2

建议：

  阶段   w           策略
  ------ ----------- --------------
  探索   0.8\~0.95   增强全局搜索
  开发   0.55\~0.8   平衡搜索
  收敛   0.3\~0.55   增强局部搜索
  停滞   临时增大    扰动部分粒子

推荐 APSO 思路。

------------------------------------------------------------------------

## 2. 收缩因子 PSO

推荐参数：

-   χ≈0.729
-   c1≈2.05
-   c2≈2.05

可降低震荡，提高稳定性。

------------------------------------------------------------------------

## 3. 动态邻域

前期采用局部邻域（Ring），后期逐渐过渡到全局邻域（Global）。

优点：

-   保持多样性
-   防止早熟
-   后期快速收敛

------------------------------------------------------------------------

## 4. 动态缩减粒子数

前期：

-   大种群

后期：

-   删除长期无贡献粒子
-   保留精英和多样性粒子

优点：

-   降低计算量
-   保持搜索能力

------------------------------------------------------------------------

## 5. 停滞恢复

检测：

-   最优值长期不变
-   多样性很低

措施：

-   保留精英
-   重启最差10%\~30%
-   局部扰动 + 随机初始化

------------------------------------------------------------------------

## 6. 后期局部搜索

推荐：

-   L-BFGS-B
-   Nelder-Mead
-   Powell
-   Pattern Search

仅在最后10%左右预算执行。

------------------------------------------------------------------------

# 三、DE 改进方案

## 1. SHADE 自适应参数

自动学习：

-   F
-   CR

避免人工调参。

------------------------------------------------------------------------

## 2. JADE 变异策略

推荐：

current-to-pbest/1

结合：

-   外部Archive
-   p-best选择

兼顾速度和精度。

------------------------------------------------------------------------

## 3. L-SHADE

推荐动态缩减种群：

-   初始：约10D\~18D（按问题调整）
-   最终：4\~10

目前属于 DE 最经典方案之一。

------------------------------------------------------------------------

## 4. 自适应选择变异策略

动态切换：

-   rand/1
-   current-to-pbest
-   current-to-rand

根据近期成功率调整概率。

------------------------------------------------------------------------

## 5. 改善边界处理

优先：

-   Reflection
-   Mid-point Repair

避免简单裁剪导致粒子堆积。

------------------------------------------------------------------------

## 6. 后期局部优化

最后阶段：

-   对最优个体执行局部搜索
-   真实目标函数验证

进一步提高最终精度。

------------------------------------------------------------------------

# 四、代理模型

适用于：

-   CFD
-   有限元
-   电力系统
-   深度学习训练

推荐流程：

代理模型预测

↓

筛选候选

↓

真实目标函数计算

↓

更新PSO/DE

注意：

代理模型只负责预筛选，最终仍必须使用真实目标函数验证。

------------------------------------------------------------------------

# 五、并行计算

推荐：

-   CPU 多线程
-   GPU 批量计算
-   异步并行

目标：

减少等待时间，提高硬件利用率。

------------------------------------------------------------------------

# 六、代码层优化

建议：

-   NumPy矩阵化
-   GPU Tensor
-   批量计算目标函数
-   Cache重复解
-   提前过滤不可行解
-   避免重复初始化模型

这些优化通常不会影响最终精度。

------------------------------------------------------------------------

# 七、推荐组合

## PSO

-   Sobol/LHS初始化
-   APSO
-   动态邻域
-   动态缩群
-   停滞恢复
-   后期局部搜索
-   并行计算

------------------------------------------------------------------------

## DE

-   L-SHADE
-   current-to-pbest
-   Archive
-   SHADE参数学习
-   动态缩群
-   停滞恢复
-   后期局部搜索

------------------------------------------------------------------------

# 八、验证方法

建议评价指标：

-   最终精度
-   收敛速度
-   函数评估次数（FEs）
-   墙钟时间
-   成功率
-   Wilcoxon/Friedman统计检验

不要仅比较迭代次数。

------------------------------------------------------------------------

# 最佳实践（推荐优先级）

1.  并行化目标函数
2.  自适应参数（APSO / SHADE）
3.  动态缩减种群（L-SHADE思想）
4.  停滞检测与恢复
5.  后期局部搜索
6.  代理模型预筛选（昂贵问题）
7.  代码向量化与缓存

以上组合通常能够在保持最终优化精度的前提下，显著减少函数评估次数并缩短实际运行时间。
