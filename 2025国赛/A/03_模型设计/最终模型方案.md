## 3. 核心内容

### 3.1 总体架构与不可变约束

全题采用同一评价内核，按“运动状态计算—几何遮蔽判定—连续区间求并—分层优化—高精度回代”五层组织。所有问题必须遵守以下规则：

1. 无人机 $i$ 受领任务后以固定 $(\theta_i,v_i)$ 等高度匀速直线飞行，$70\le v_i\le140\,\mathrm{m/s}$。
2. 第 $ik$ 枚弹仅以投放时刻 $t^r_{ik}$ 和起爆延时 $\tau_{ik}$ 作为独立时间变量；投放点 $\mathbf r_{ik}$、起爆点 $\mathbf q_{ik}$ 必须由轨迹正向计算。
3. 同机相邻投放满足 $t^r_{i,k+1}-t^r_{ik}\ge1\,\mathrm s$；问题3固定投放3枚，问题5每机至多3枚。
4. 取 $g=9.8\,\mathrm{m/s^2}$。单云团在起爆后至多20秒有效，球心以 $3\,\mathrm{m/s}$ 下沉、球半径为 $10\,\mathrm m$；当云团顶部 $c_{ik,z}(t)+R_s<0$ 时立即失效。
5. 同一时刻允许多个云团分别遮挡目标的不同可见点；当每个目标采样点均被至少一个有效云团遮挡时才计为有效遮蔽。总时长为联合遮蔽区间长度 $T_j=|\mathcal C_j|$，时间重叠不得重复计时。
6. Excel统一填写从 $+x$ 轴逆时针计量的 $[0,360^\circ)$ 航向角、按全局投放顺序计算的主要目标新增遮蔽时长，并对所有数值保留3位小数；完整精度结果另存用于回代。

### 3.2 统一运动学与弹道子模型

对导弹 $j$、无人机 $i$ 和烟幕弹 $k$，采用：

$$
\mathbf m_j(t)=\mathbf m_j^0-V_Mt\frac{\mathbf m_j^0}{\|\mathbf m_j^0\|},
\qquad
\mathbf u_i(t)=\mathbf u_i^0+v_it\mathbf d_i,
$$

$$
\mathbf r_{ik}=\mathbf u_i(t^r_{ik}),\qquad
t^e_{ik}=t^r_{ik}+\tau_{ik},
$$

$$
\mathbf q_{ik}=\mathbf r_{ik}+v_i\tau_{ik}\mathbf d_i-\tfrac12g\tau_{ik}^2\mathbf e_z,
$$

$$
\mathbf c_{ik}(t)=\mathbf q_{ik}-3(t-t^e_{ik})\mathbf e_z.
$$

其中 $\mathbf d_i=(\cos\theta_i,\sin\theta_i,0)$，并要求 $q_{ik,z}\ge0$。该模块是投放点、起爆点和所有方案可行性检查的唯一来源。

### 3.3 统一遮蔽评价器

#### 3.3.1 主评价器：轮廓采样 + 时间边界求根

1. 对导弹视角下的圆柱可见轮廓生成采样集 $\mathcal P_N$。
2. 对每个 $\mathbf p_n\in\mathcal P_N$，计算云团中心到导弹—目标视线段的最短距离 $d_{ijk}(t,\mathbf p_n)$。
3. 对每个目标采样点，检查是否至少存在一个有效云团满足 $d_{ijk}(t,\mathbf p_n)\le R_s$；当全部采样点均通过该检查时，令联合遮蔽指示 $H_j(t)=1$。不同采样点允许由不同云团遮挡。
4. 在全部云团有效窗的端点划分下粗扫 $H_j(t)$ 的状态变化，再在边界区间用二分或布伦特法求遮蔽边界；由 $H_j(t)=1$ 的时刻直接形成联合区间 $\mathcal C_j$。单弹完整遮蔽区间仅作为诊断量。
5. 以 $T_j=|\mathcal C_j|$ 作为对应导弹的有效遮蔽时长。

#### 3.3.2 双层精度控制

- **快速评价器：** 固定轮廓采样和较粗时间扫描，供问题2—5的候选生成和优化迭代使用。
- **高精度评价器：** 加密/自适应轮廓采样，必要时使用连续表面最不利点 $D_{ijk}(t)$，供问题1最终结果和问题2—5最终方案回代使用。
- **对照评价器：** 目标中心点视线，仅用于调试和敏感性比较，不作为主结论。

高精度评价器与快速评价器的时长差、空间采样加密差和时间边界残差必须记录；未通过收敛标准的方案不得进入结果表。

### 3.4 问题1：固定策略评价方案

**模型：1B主算 + 1A高精度复核 + 1C基准对照。**

1. 由题设固定策略计算 FY1 的投放点、起爆时刻和起爆点。
2. 用主评价器得到遮蔽区间与总时长；主输出为高精度回代后的总时长，不是粗网格累计值。
3. 用连续表面最不利点或自适应极高密度采样复核主结果；用中心点模型检验几何和程序逻辑。
4. 输出：投放点、起爆点、有效时间窗、遮蔽区间、总时长、边界残差和收敛结果。

**失效处理：** 若1B与高精度复核不收敛，暂停向问题2传递评价器；若中心点与轮廓口径差异过大，不选择较大数值，而是解释目标尺寸带来的差异。

### 3.5 问题2：单机单弹优化方案

**模型：2B几何反演初值 + 2A全局—局部连续优化，2C网格对照。**

1. 通过 M1—真目标视线束的运动和 FY1 可达域，构造理想起爆时空区域，反演得到多组可行初值。
2. 以 $\mathbf x_2=(\theta_1,v_1,t^r_{11},\tau_{11})$ 为决策向量，最大化 $T_1$；采用无导数全局搜索生成候选，再对高质量候选作局部精修。
3. 约束采用参数边界和正向轨迹编码，不用任意投放/起爆坐标替代；拒绝 $q_{11,z}<0$ 的候选。
4. 在缩小后的高值区域运行分层网格，核对全局搜索没有遗漏显著高值区域。
5. 对最终候选使用高精度评价器回代，输出航向、速度、投放点、起爆点、遮蔽区间和时长。

**失效处理：** 若全局搜索重复运行不稳定，增加初值数量并扩大反演候选区；若粗网格发现明显优于搜索结果的区域，重新启动全局搜索；若无可行遮蔽，保留零时长而不伪造投放坐标。

### 3.6 问题3：固定三弹时序协同方案

**模型：3B边际覆盖构造 + 3A联合精修。**

1. 决策向量为

$$
\mathbf x_3=(\theta_1,v_1,t^r_{11},\tau_{11},t^r_{12},\tau_{12},t^r_{13},\tau_{13}).
$$

2. 在同一 $(\theta_1,v_1)$ 约束下，先优化第一枚；第二、第三枚面向当前未被完整覆盖的“目标点—时间”区域最大化联合遮蔽边际贡献，形成三弹互补可行初解。
3. 对全部8个变量联合精修，目标为由多云团共同覆盖判据得到的 $T_1=|\mathcal C_1|$，而非三个单弹完整遮蔽时长之和或其区间简单并集。
4. 检查三次投放均存在、严格有序、间隔不小于1秒、起爆点均在地面上方；按投放顺序计算每枚弹对M1的新增遮蔽时长，并报告独立诊断区间、移除边际贡献和最终联合区间。

**失效处理：** 若某枚弹长期零边际贡献，优先调整三弹时序和共享航向速度；不得以“不投放”规避固定三弹约束。若联合精修破坏间隔约束，采用有序参数化或可行性修复后重算。

### 3.7 问题4：三机单弹协同方案

**模型：4B候选组合 + 4C分块精修 + 小范围4A联合精修。**

1. 对 FY1、FY2、FY3 分别运行问题2接口，保留不同遮蔽时段和空间位置的多样化单弹候选，而不只保留单机最优候选。
2. 从每架无人机候选集中各选一条，以 M1 的联合完整遮蔽时长最大为准则形成初始组合；允许不同无人机的云团共同覆盖不同目标点。
3. 固定另外两架无人机，针对尚未覆盖的“目标点—时间”区域更新一架无人机的 $(\theta_i,v_i,t^r_{i1},\tau_{i1})$；轮换至目标不再改善。
4. 仅对最佳少量组合在其邻域进行12维联合精修，最终使用高精度评价器回代。
5. 按三枚弹的全局投放顺序计算对M1的新增遮蔽时长，输出三架无人机各自的运动参数、投放点、起爆点、顺序新增时长、移除边际贡献及联合遮蔽区间。

**失效处理：** 若候选库扩大后方案明显改变，增加候选覆盖不同时间段的比例；若分块更新顺序造成强烈差异，轮换顺序并用多初始组合；联合精修只接受通过可行性和高精度回代的改进。

### 3.8 问题5：混合分层协同方案

**模型：5A完整路线候选库 + 0—1最大覆盖选择 + 连续精修。**

1. 对每个“无人机—导弹”组合生成单弹候选；再将同一无人机最多三枚弹的投放序列组合为完整路线。每条路线必须固定一组 $(\theta_i,v_i)$，并含0—3枚满足间隔和起爆高度约束的烟幕弹。
2. 对每条路线预计算其对 M1—M3 各目标采样点的视线遮挡状态，并在时间网格上构造“路线—导弹—目标点—时间”覆盖矩阵。
3. 用 $y_{ir}\in\{0,1\}$ 表示是否选择无人机 $i$ 的路线 $r$，满足 $\sum_{r\in\mathcal R_i}y_{ir}\le1$。所有烟幕对M1—M3产生的实际几何遮蔽均计入对应 $T_j$，任务标签不作为覆盖门控条件。
4. 采用两阶段字典序目标：第一阶段最大化 $J_{\mathrm{sum}}=T_1+T_2+T_3$；第二阶段在 $J_{\mathrm{sum}}\ge J_{\mathrm{sum}}^\ast-\varepsilon_J$ 下最大化 $J_{\min}=\min(T_1,T_2,T_3)$。
5. 求得离散路线组合后，固定路线结构，在连续变量上局部精修航向、速度、投放时刻和起爆延时；按多云团逐点共同覆盖判据重新计算连续联合区间及两阶段目标。
6. 输出每枚实际投放弹的无人机、编号、主要目标导弹、航向角/速度、投放点、起爆点和按投放顺序计算的新增时长，并按 `result3.xlsx` 表头填写。

**均衡性处理：** 字典序两阶段是正式主方案，不再仅作为敏感性对照。第二阶段允许的总和损失上限 $\varepsilon_J$ 取高精度评价器的总时长数值容差，并在运行清单中记录。

**失效处理：** 若候选库或时间网格加密后结果大幅变化，扩充候选、去除支配路线后重解；若整数规划不可用，使用固定任务分配下的连续优化或5B层次化遗传方案作为备用，但必须报告多随机种子波动，不能宣称全局最优。

### 3.9 实现顺序与共用接口

1. 实现并验证参数、运动学、弹道、云团、线段距离和区间并集模块。
2. 完成问题1的三层评价与收敛检验，冻结通过检验的评价器接口。
3. 实现问题2的反演候选、全局—局部优化和网格对照。
4. 依次扩展问题3的三弹时序、问题4的多机候选组合、问题5的完整路线与离散选择。
5. 每一问均先快速评价、后高精度回代；未经回代的候选不能导出到 Excel。

建议的内部接口为：`uav_position()`、`missile_position()`、`bomb_position()`、`smoke_center()`、`line_of_sight_blocked()`、`find_coverage_intervals()`、`merge_intervals()`、`evaluate_solution()`、`check_feasibility()` 和 `export_results()`。接口名称仅说明功能，不限定语言或程序框架。

### 3.10 统一检验与论文呈现

| 检验类别 | 最低要求 | 对应问题 |
|---|---|---|
| 运动学回代 | 导弹速度、无人机高度和速度、投放/起爆点轨迹、起爆高度均满足约束 | Q1—Q5 |
| 几何边界 | 临界时刻的最不利视线距离接近 $10\,\mathrm m$；烟幕位于导弹与目标之间 | Q1—Q5 |

论文应按“统一评价内核—问题递进扩展—高精度回代验证”展开：问题1负责验证内核，问题2负责建立单弹可行优化，问题3和问题4分别验证时间协同与空间协同，问题5完成任务分配与路线选择。创新点应落在保守轮廓判据、可达性参数化、区间边界求根和分层离散—连续协同上。

## 4. 关键结论

1. 全题唯一主线是可达性参数化的运动学/弹道模型与“目标点逐点覆盖—多云团联合遮蔽—连续区间计时”评价器；投放点和起爆点不是独立决策坐标。
2. 问题1以高精度评价器建立可信基准；问题2—Q5只在该评价器通过收敛检验后依次扩展。
3. 问题3固定三弹，采用边际覆盖初解和联合精修；问题4采用候选组合和分块精修；问题5采用完整路线候选、0—1覆盖选择和连续回代。
4. 问题5采用“总和优先、最短时长次优”的字典序目标，并让所有实际几何遮蔽计入对应导弹时长。
5. 所有最终时长必须以高精度回代值和已核验模板字段为准，不使用粗网格或优化器中间值直接填表。
