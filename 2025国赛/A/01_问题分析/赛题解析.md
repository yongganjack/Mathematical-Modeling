
# 赛题解析

## 1. 文档目的
基于赛题原文与数据说明，对赛题背景、总体目标、各问题类型及建模难点进行统一解析，为后续模型设计提供问题抽象基础。

## 2. 输入信息来源
- 赛题原文.md
- 数据说明.md
- 补充要求.md：未提供

## 3. 核心内容

### 3.1 研究对象
研究对象包括无人机、烟幕干扰弹、烟幕云团、来袭导弹及真/假目标组成的三维动态系统。

### 3.2 总体目标
设计无人机飞行方向、飞行速度、烟幕弹投放位置及起爆位置（或时刻），使烟幕对真目标的有效遮蔽总时长尽可能长。

### 3.3 各小问题题型
|问题|类型|主要特点|
|---|---|---|
|问题1|评价+几何计算|固定策略下计算有效遮蔽时长|
|问题2|优化|单机单弹最优投放|
|问题3|优化+调度|单机多弹协同优化|
|问题4|优化+协同决策|多机单弹协同|
|问题5|综合优化|多机多弹多目标联合优化|

### 3.4 主要建模难点
1. 三维运动轨迹统一描述。
2. 烟幕有效遮蔽判定。
3. 投放、起爆与无人机运动耦合。
4. 多弹、多机、多导弹协同优化。
5. 时空约束及连续时间优化。

## 4. 关键结论
- 赛题具有明显递进结构，由确定性计算逐步发展为大规模优化。
- 后续模型可采用统一运动学模型，在不同问题增加决策变量。
- 目标函数均围绕有效遮蔽时间展开。
